#Cafe Sales Performance Dashboard

Welcome to the Cafe Sales project! This dashboard analyzes sales performance to uncover key business insights.

##Project Overview
* **Tool:** Power BI
* **Objective:** Clean, model, and visualize cafe sales data to track revenue, popular items, and peak periods.

##Key Features & Insights
* **Interactive Visuals:** Dynamic charts showing sales trends and category breakdowns.
* **Data Handling:** Managed data cleaning and processed missing or unknown values effectively.
* **DAX Measures:** Used custom measures to calculate total sales and key metrics.
